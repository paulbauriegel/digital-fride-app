The Vulkan backend uses dynamic dispatch for vkGetPhysicalDeviceFeatures2 so the runtime keeps the
app's API 26 minimum while using Vulkan 1.2 on supported devices. This changes three direct calls in
ggml/src/ggml-vulkan/ggml-vulkan.cpp to the backend's existing DispatchLoaderDynamic instance.

The arm64 llama-mtmd-cli executable, Vulkan backend, CPU fallback variants, and their required
shared libraries were stripped of debug symbols. The executable is packaged as
libllama_mtmd_cli.so so Android extracts it into the application native library directory.
